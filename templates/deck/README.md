# Deck Starter

Deck starter 3 สไลด์ตัวอย่าง (ปก / สถิติตัวเลขใหญ่ / เนื้อหาแบบ grid) สำหรับสร้าง deck ใหม่ได้เร็ว
ไม่มี build step — เปิด `index.html` ตรง ๆ ได้เลย

## 1. รันยังไง

เปิด `index.html` ด้วย double-click หรือลากเข้าเบราว์เซอร์ได้ทันที (ใช้ path แบบ `file://`)

หรือรันเซิร์ฟเวอร์ local:

```sh
bash serve.sh
```

แล้วเปิด `http://127.0.0.1:8080`

ควบคุมสไลด์ด้วยลูกศรซ้าย/ขวา, คลิกซ้าย/ขวาของจอ, ปัดซ้าย/ขวาบนมือถือ, หรือปุ่มลูกศรที่มุมขวาล่าง
กด `F` เพื่อเต็มจอ, กด `H` เพื่อซ่อน/แสดงตัวควบคุม

## 2. แก้ข้อความสไลด์ที่ไหน

ทุกข้อความอยู่ใน `index.html` (ไม่มีไฟล์ data แยก):

- **สไลด์ 1 (ปก)** บรรทัดประมาณ 18–27 — หมวดหมู่/วันที่, หัวข้อ (`<h1>`), คำโปรย, แท็กไลน์, ข้อความท้ายสไลด์
- **สไลด์ 2 (สถิติ)** บรรทัดประมาณ 33–46 — หัวข้อสไลด์, ตัวเลข `data-value` และหน่วยของแต่ละ `<article>`, แหล่งอ้างอิงใน `<footer class="citation">`
- **สไลด์ 3 (เนื้อหาแบบ grid)** บรรทัดประมาณ 52–58 — หัวข้อสไลด์ และหัวข้อย่อย/คำอธิบายในแต่ละ `<article>`

ตัวเลขในสไลด์สถิติจะนับขึ้นอัตโนมัติ (แก้ที่ `data-value` และ `data-decimals`)

## 3. เพิ่มสไลด์ใหม่ยังไง

ต้องแตะ 2 ไฟล์:

1. **`index.html`** — คัดลอกทั้งบล็อก `<section class="slide ...">` ของสไลด์ที่ใกล้เคียงที่สุด (ปก/สถิติ/grid) มาวางต่อท้ายก่อนแท็ก `<nav class="presenter-ui">` แล้วแก้เนื้อหา แก้เลขรวมสไลด์ในช่อง `<span>3</span>` ที่แถบควบคุมด้านล่าง (บรรทัดประมาณ 65) ให้ตรงกับจำนวนสไลด์ใหม่
2. **`styles.css`** — ถ้าใช้ layout เดิม (`.slide-cover`, `.slide-stats`, `.slide-grid`) ไม่ต้องแก้ CSS เพิ่ม ถ้าต้องการ layout ใหม่ ให้เพิ่ม class และ CSS block ใหม่ต่อท้ายไฟล์

ไม่ต้องแก้ `app.js` — ระบบนำทาง, การนับสไลด์, progress bar และ reveal animation อ่านจากจำนวน `.slide` ใน DOM อัตโนมัติ ไม่ผูกกับหมายเลขสไลด์ตายตัว

## 4. ใส่รูปยังไง

1. วางไฟล์รูปในโฟลเดอร์ `assets/` (เช่น `assets/my-image.webp`)
2. ใน `index.html` แทนที่กล่อง `<figure class="image-slot">...</figure>` ในสไลด์ปก (บรรทัดประมาณ 23–26) ด้วย:

   ```html
   <img src="assets/my-image.webp" alt="คำอธิบายรูปสำหรับผู้ใช้ screen reader">
   ```

3. path ต้องเป็น relative เสมอ (ไม่ขึ้นต้นด้วย `/`) เพื่อให้ทำงานได้ทั้งบน `file://` และ GitHub Pages
