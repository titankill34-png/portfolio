สร้างระบบ AI ที่ส่งงานได้จากมือถือ

ข้อจำกัดตั้งต้นคือมีแค่มือถือ Android เครื่องเดียว ไม่มีคอมพิวเตอร์ให้ใช้ คำถามจึงไม่ใช่ "จะสร้างอะไร" แต่คือ "จะทำงานเขียนโค้ดให้เสร็จได้อย่างไรในข้อจำกัดนี้"

คำตอบคือรันทุกอย่างบน Termux แล้วใช้ Claude Code เป็น worker ที่ทำงานเขียนโค้ดจริง ส่วน GitHub Issues ทำหน้าที่เป็นคิวงาน เปิด issue แล้วติด label งานก็จะถูก watcher หยิบไปทำเองโดยอัตโนมัติ

52 วินาที

วัดได้จริง: จากเปิด issue ถึงได้ pull request ใช้เวลา 52 วินาที

ปัญหาที่เจอ และวิธีแก้

  1. 01

    Claude Code เวอร์ชันใหม่ไม่มี binary สำหรับ Android — ต้องล็อกเวอร์ชันไว้ที่ 2.1.112 เพื่อให้ยังรันได้บนอุปกรณ์นี้

  2. 02

    โควตาหมดกลางงาน — แก้ด้วยการแยกเคส "โควตาหมด" ออกจาก "งานล้มเหลว" ให้ชัดเจน แล้วคืนงานนั้นเข้าคิว รอลองใหม่เองโดยไม่ต้องสั่งซ้ำ

  3. 03

    watcher หลายตัวแย่งเขียน repo เดียวกัน — แก้ด้วย lock file หนึ่งตัวต่อหนึ่ง repo ป้องกันการชนกัน

  4. 04

    ไฟล์สถานะถูกเขียนลง branch ที่ worker กำลังทำงานอยู่ — แก้ด้วยการเขียนสถานะผ่าน GitHub API ตรงเข้า main แทนที่จะ commit ลง branch งาน

ระบบนี้ต้องรอดจากการที่เครื่องรีบูตเองได้ด้วย จึงใช้ tmux คู่กับ Termux:Boot เพื่อให้ session กลับมาทำงานต่อได้โดยไม่ต้องเปิดเองใหม่ทุกครั้ง

สิ่งที่ได้จากงานนี้คือตัวระบบเอง ไม่ใช่สิ่งที่มันสร้างขึ้นมา
